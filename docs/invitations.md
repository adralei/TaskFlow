
# TaskFlow - Team Invitations

## Invitation Permissions

Only workspace admins can invite new team members.

Members with the regular member role cannot send invitations.

## Invitation Button Behavior

The invitation button is disabled when the workspace
has reached its subscription member limit.

The button can also be disabled when the current user
does not have invitation permissions.

## Troubleshooting Invitations

If a user cannot invite a new team member:

1. Check the user's workspace role.
2. Check the current subscription plan.
3. Compare the current member count with the plan limit.
4. Verify whether the invitation button is disabled.

If the member limit has been reached, the workspace admin
can remove an existing member or consider upgrading the plan.

Do not claim that the issue is resolved until the customer
confirms that invitations are working again.
